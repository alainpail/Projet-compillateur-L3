Le rôle du compilateur est de transformer le code du programme donné en un code exécutable (ici, du code MaPile). Il est crucial de générer les fichiers compilés à la fin de la compilation (en appelant les méthodes constGen et constObj). Cela vous aurait permis de vous rendre compte que votre code compilé est clairement incorrect.

Les instructions d’écriture n’ont pas d’argument, elles affichent (en fonction du type donné) la dernière valeur empilée (ce qui est déjà fait par le calcul de l'expression).

La valeur d’une variable est accessible et affectable via son adresse qui est donnée par la colonne d’info de la table des symboles.

Le branchement conditionnel d’un ttq doit permettre de sortir de la boucle, en branchant sur le code après le branchement inconditionnel qui permet de re-vérifier la condition après une itération de la boucle.

Globalement, il y a clairement des notions qui ne semblent pas comprises. Je vous conseil de reprendre votre code en détail avant la prochaine séance et d’essayer de finir le cond, pour ne pas prendre trop de retard.
